# 执行与性能

当前引擎使用单一 `ExecCode` 字流和栈 VM。编译器发布指令、控制流边界与数值区域；`vm/execute.rs` 执行指令，驱动器处理调用、属性语义、异常与挂起。普通绑定写入按所有权转移，命名属性读取在同一选择流程中处理数据、访问器和完整缺失。捕获变量与形状使用各自的类型化 arena。

性能结论以受测源码、二进制、负载和原始样本为单位。改动执行路径时，同时核对语义、局部操作成本、完整程序时间、编译成本和内存生命周期。
