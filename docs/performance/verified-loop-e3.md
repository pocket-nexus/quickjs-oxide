# E3：当前帧表示与直接消费实验

**实现和正确性合同已完成，收益门槛未通过；保留为实验，未采纳进主线。**

比较基线是 E2 `afadba63`，最终运行时代码为 `f0e98a3b`。
全部计数和原生计时使用 Rust 1.88、相同配置的普通 release、无 PGO、无 profiling
计数开销。复用既有冻结工作量、N/2N/4N 探针、输出校验和二进制回执。
本次没有重跑 Boa，也没有进行原版 adaptive Score 验收。

## 分提交实现

| 提交 | 实际改动 |
| --- | --- |
| `869e3379` | 操作数由一个共享 `Vec<JsValue>` 规范持有，与绑定存储分开；更新普通/构造参数移动、native 参数转交、getter、帧切换和清理 |
| `455d6b30` | 一个执行片段借用当前帧的绑定/操作数切片；深度保存在局部，作用域退出发布；避免每条操作重新建立槽位视图 |
| `0be51bfe` | 数值算术、比较、常量、局部/参数读写消费已发布的静态事实；删除这些消费者的重复准入与 Result 运输 |
| `f0e98a3b` | 根据第三步测到的 Dw 增长，缩减当前视图的绑定元数据；四个区域端点变为一个参数边界，删除 FrameWindow 的冗余端点 |

第四个提交是有测量依据的小修正。相对第三步，它使 R/D 的 Ir 再下降
0.43%/0.61%，Dw 再下降 0.82%/1.09%；没有消除累计 Dw 增长。
64 位普通构建的当前帧视图由 80 降到 56 字节，FrameWindow 由 88 降到 80 字节。
这些尺寸比较指第四步前后，不代表相对 E2 的总元数据减少。

### 所有权与边界

- 活跃操作数前缀拥有引用；非活跃后缀只能是 Undefined 或 immediate，不拥有对象、字符串、Symbol 等引用。
- 数值归约可留下失活的 immediate；移出拥有引用的值仍用 replacement。没有镜像操作数存储和同步复制。
- 帧安装先完成容量预留及 fallible 准备，再移动调用者参数。切片借用结束后才能扩容或切帧。
- 保留 B1 已有的 native 直接完成路径。通用 owning argv 仍使用原来的复用缓冲，没有宣称它原来或现在全部借用 caller slice。
- 深度在 GC 服务、错误、回调及执行片段退出时发布；Drop 负责失败路径的发布。绑定仍保留 capture、TDZ 等语义。
- 发布字节码的静态合同支持便宜消费；内部对象/数组分配生产者仍保留可失败的 checked commit，提交失败时释放新 owner。
- 所有访问仍是 safe Rust，保留切片边界保护。纯 JsValue 局部变量表示未纳入 E3。

**GC 合同按实际实现校准。** 当前 trial-deletion 收集器通过强引用计数减去 heap
内部边发现外部 owner，并不扫描 SlotStore。本次保留活跃操作数的 owning edge，
没有新增重复根扫描。挂起状态仍通过既有 freeze/thaw 发布其边。

## 第三步及最终机制结果

计数斜率排除了固定启动/解析成本，并由 N→2N、2N→4N 验证线性。
最终两段斜率差异均小于 0.0004%。表中单位是每次 **JS 循环迭代**。

| 探针/指标 | E2 | E3 首版 | E3 最终 | 固定 QuickJS 参考 |
| --- | ---: | ---: | ---: | ---: |
| 数值循环 Ir | 1074 | 875 | **874** | 167 |
| 数值循环 Dr | 253 | 205 | 203 | 51 |
| 数值循环 Dw | 133 | 136 | **136** | 19 |
| 空循环 Ir | 276 | 279 | 277 | 90 |
| 空循环 Dr | 62 | 61 | 57 | 31 |
| 空循环 Dw | 27 | 32 | **32** | 10 |

数值循环 Ir 相对 E2 下降 **18.62%**，但写访问增加 **2.26%**；空循环没有指令收益，
写访问增加 **18.52%**。不能用数值循环的收益代表全部字节码路径。

profiling 诊断构建的 N→2N 斜率确认数值循环每次实际分派 **12 条**：
GetArg×2、PushI32×2、Drop×2，以及比较分支、NumberLocalInc、SetLocal、Sub、SetArg、Goto 各一次。
此诊断在第三步构建上采集；第四步只缩减绑定元数据，没有改变编译、发布或 opcode 消费顺序。
空循环的 4 次分派复用此前诊断，其编译序列同样未改变。

最终数值循环为 **72.83 Ir/实际分派**（E2 约 89.5）。
**≤40 Ir/分派、400–500 Ir/迭代两项目标均未达到。**
R/D 整体下降一到两成的假设也没有兑现。

## 剩余成本与资源交换

地址账本只计 self cost，排除调用边的 inclusive cost；每个 object/指令地址只出现一次。

下面按汇编形式互斥归组，不能直接当作源码职责归因。

| --- | ---: |

`[0x5da2bb, 0x5da35e)` 合计 340 Ir/迭代；它是上述账本的另一种视图，不能重复相加。

这说明新的切片表示还不足以达到目标。后续设计应核对热循环的状态驻留、

  本次未做完整 GC 停顿、编译成本或正式资源验收。

## 正确性与停止点

最终表示通过 Rust 1.88 的 **2334 个库测试**、**68 个 profiling stack 测试**、
profiling Clippy `-D warnings`；focused Test262 **6844/6844** 的完整结果向量与冻结回执一致。
全部微基准、V8 重放及 RSS 取样的工作量/输出校验通过。

新增行为见证覆盖：

- 操作数上持有循环对象时收集保留它，退役最后 owner 后可收集。
- 计算 key 的回调分配 20,000 个循环对象时，调用者操作数上的 receiver 保持存活。
- 执行切片发生错误、显式 GC publication 和作用域退出时，深度及 root 一致。
- 数值归约留下 inactive immediate 后可复用该槽，inactive 区没有引用 owner。

focused 工具的前几次启动受继承 Git 环境及磁盘空间影响而停止；最终运行复用缓存输入、
在 tmpfs 完成验证，使用系统 Git/Node。没有修改 runtime 或校验规则作为绕过。
未运行完整 Test262/native/wasm 阶段验收，因此不宣布整个架构迁移已验收。
