# Generated Unicode table sources

This directory holds the checksum-pinned Rust Unicode tables generated from a
pinned upstream version. Ordinary builds read these files directly without
running generators.

## Files and subdirectories

- [unicode_case_tables.rs](unicode_case_tables.rs): case-conversion tables.
- [unicode_ident_tables.rs](unicode_ident_tables.rs): identifier character tables.
- [unicode_normalize_tables.rs](unicode_normalize_tables.rs): normalization tables.
- [unicode_property_tables.rs](unicode_property_tables.rs): property-set tables.
