Why oxide

  

    
0 unsafe
Safe Rust

      
Every crate in the workspace sets forbid(unsafe_code): the engine, the CLI and the WebAssembly bindings.

    
≈1× QuickJS
QuickJS-class speed

      
Register bytecode, inline caches and NaN-boxed values keep run time level with QuickJS on the V8 v7, Octane and Are-We-Fast-Yet suites.

    
Native + WASM
Runs where you need it

      
Embed it in a Rust application, use the native qjs command line, or ship the WebAssembly build to the browser, like the demo above.

Start here

  
Add the two crates, create a runtime, evaluate a script and read the result.

  

    

      
Cargo.toml

      
[dependencies]
quickjs-oxide = { git = "https://github.com/pocket-nexus/quickjs-oxide" }
quickjs-oxide-host = { git = "https://github.com/pocket-nexus/quickjs-oxide" }

      
src/main.rs

      
use quickjs_oxide::engine::api::core::{Runtime, Value};
use quickjs_oxide_host::SystemHost;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let runtime = Runtime::new_with_host_services(SystemHost::default());
    let mut context = runtime.new_context()?;
    let value = context.eval("[1, 2, 3].map((x) => x * 2).join()")?;
    if let Value::String(text) = value {
        println!("{}", text.to_utf8_lossy()); // 2,4,6
    }
    Ok(())
}
